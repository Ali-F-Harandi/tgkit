# tgkit — راهنمای فارسی (برای همه)

این راهنما برای **همه‌ی افراد** نوشته شده — هیچ دانش قبلی درباره‌ی API تلگرام لازم نیست. اگر بلدید در ترمینال دستور کپی کنید، tgkit بلدید.

**فارسی** | [English](guide.md)

---

## tgkit چیست؟ (در یک پاراگراف)

tgkit یک ابزار خط فرمان است که فایل‌ها را بین کامپیوتر شما و کانال‌های تلگرام جابه‌جا می‌کند: **دانلود** فایل از لینک یک پیام، **آپلود** فایل به کانال خودتان، **کپی** پیام‌ها بین کانال‌ها و **اسکن** کل تاریخچه‌ی یک کانال داخل یک دیتابیس قابل جستجو. همه‌ی کارها از طریق بات‌هایی که خودتان می‌سازید انجام می‌شود؛ پس نه لاگین انسانی لازم است و نه چیزی با سرور کسی دیگری به اشتراک گذاشته می‌شود.

## چرا از خود تلگرام استفاده نکنیم؟

یک جمله: **محدودیت حجم فایل**. همان API «ساده‌ی» تلگرام که اکثر ابزارها استفاده می‌کنند، پنهانی دانلود را به **۲۰ مگابایت** و آپلود را به **۵۰ مگابایت** محدود می‌کند. tgkit از همان پروتکل داخلی‌ای استفاده می‌کند که کلاینت‌های اصلی تلگرام استفاده می‌کنند (MTProto)، پس فایل‌ها تا **۲ گیگابایت** را مدیریت می‌کند — و با vault حجم کل نامحدود می‌شود. همه‌ی این‌ها خودکار است؛ لازم نیست بهش فکر کنید.

| کاری که می‌خواهید بکنید | محدودیت ابزارهای معمولی | محدودیت با tgkit |
|---|---|---|
| دانلود یک فایل | ۲۰ مگابایت | **۲ گیگابایت** |
| آپلود یک فایل | ۵۰ مگابایت | **۲ گیگابایت** (با vault نامحدود) |
| دانلود ۵۰۰ فایل در یک شب | کلیک دستی | یک دستور |

## بخش ۱ — راه‌اندازی (۱۰ دقیقه، فقط یک بار)

### مرحله ۱: نصب پایتون و tgkit

پایتون ۳.۱۰ یا بالاتر لازم است. چک کنید:

```bash
python3 --version
```

بعد tgkit را نصب کنید:

```bash
git clone https://github.com/Ali-F-Harandi/tgkit.git
cd tgkit
pip install -e .
```

تست کنید که کار می‌کند:

```bash
tgkit --version
```

### مرحله ۲: گرفتن کلیدهای API تلگرام

این دو کد (‏api_id و api_hash) به تلگرام می‌گویند که *خود شما* در حال اتصال هستید، نه یک غریبه.

1. در مرورگر https://my.telegram.org را باز کنید و با شماره تلفن‌تان لاگین کنید (کد در خود تلگرام برایتان می‌آید).
2. روی **API Development Tools** کلیک کنید.
3. فرم را پر کنید: هر عنوانی برای اپ (مثلاً «ابزار من»)، هر اسم کوتاهی، پلتفرم را «Other» بگذارید.
4. بعد از ثبت، **App api_id** (یک عدد مثل `21724`) و **App api_hash** (یک رشته‌ی طولانی مثل `3e0cb5ef...`) را می‌بینید. هر دو را ذخیره کنید.

### مرحله ۳: ساخت بات

کارهای واقعی را بات‌ها انجام می‌دهند. برای شروع یک بات کافی است.

1. در تلگرام، چت **@BotFather** را باز کنید (تیک آبی دارد).
2. `/newbot` را بفرستید، یک اسم نمایشی انتخاب کنید، بعد یک یوزرنیم که به `bot` ختم شود (مثلاً `myfiles_bot`).
3. BotFather یک **توکن** مثل `8866132706:AAGSmU4xNBLgoqi9ceYapHi-PEB57MvDm3I` برایتان می‌فرستد. ذخیره‌اش کنید.

### مرحله ۴: وصل کردن همه چیز

```bash
# ساخت فایل کانفیگ
tgkit init

# معرفی بات به tgkit
tgkit bot add 8866132706:AAGSmU4xNBLgoqi9ceYapHi-PEB57MvDm3I
```

حالا فایل کانفیگ را با هر ویرایشگر متنی باز کنید (مسیرش را خودش نشان می‌دهد — معمولاً `~/.tgkit/config.json`) و دو فیلد مرحله ۲ را پر کنید:

```json
"api": {
    "api_id": 21724,
    "api_hash": "3e0cb5efcd52300aec5994fdfc5bdc16",
    ...
}
```

### مرحله ۵: چک سلامت جادویی

```bash
tgkit doctor --deep
```

این دستور همه چیز را چک می‌کند: نسخه‌ی پایتون، پکیج‌های نصب‌شده، فایل کانفیگ، کلیدهای شما، تک‌تک توکن‌های بات‌ها (به صورت زنده)، اینترنت، فضای دیسک، و حتی یک لاگین آزمایشی واقعی. اگر چیزی خراب باشد، **دقیقاً می‌گوید برای درست کردنش چه تایپ کنید**. وقتی `✓ All checks passed` چاپ کرد، کار تمام است.

## بخش ۲ — دانلود فایل

لینک یک پیام تلگرام را دارید، مثل `https://t.me/c/3786156476/46839` (روی هر پیام کانال راست‌کلیک کنید → Copy Message Link).

```bash
# یک فایل
tgkit fetch https://t.me/c/3786156476/46839

# چند فایل، با حفظ ترتیب
tgkit fetch https://t.me/c/3786156476/46815 https://t.me/c/3786156476/46813

# داخل یک پوشه‌ی خاص
tgkit fetch https://t.me/c/3786156476/46839 --out ~/Downloads
```

همین. فایل‌ها در پوشه‌ی فعلی (یا پوشه‌ی `--out`) می‌ریزند و روی فایل موجود هرگز بدون اجازه بازنویسی نمی‌شود (خودکار به `file (1).zip` تغییر اسم می‌دهد).

**فایل خیلی بزرگ باشد چه؟** مهم نیست. فایل ۱۲۲ مگابایتی، ویدیوی ۹۰۰ مگابایتی — دستور `fetch` خودش از MTProto استفاده می‌کند و نوار پیشرفت زنده نشان می‌دهد. اگر لینک شما یک پکیج vault باشد (فایلی که تکه‌تکه شده)، خودش متوجه می‌شود و خودکار به حالت vault سوییچ می‌کند.

**نکته‌ی مهم:** بات باید بتواند فایل را ببیند. برای کانال‌های خصوصی، بات را اول عضو یا ادمین همان کانال کنید — بات فقط از کانال‌هایی دانلود می‌کند که عضو آن‌ها باشد.

## بخش ۳ — آپلود فایل

```bash
# آپلود به یک کانال (یوزرنیم @دار یا شناسه -100... )
tgkit send report.zip --to @mychannel

# چند فایل با کپشن
tgkit send a.zip b.zip --to @mychannel --caption "بکاپ پروژه"

# فایل بزرگ؟ همان دستور. فایل ۸۰۰ مگابایتی هم مشکلی ندارد.
tgkit send big_video.mkv --to @mychannel
```

برای هر فایل آپلودشده، یک لینک قابل به‌اشتراک‌گذاری `t.me` می‌گیرید.

شرط کانال مقصد: بات شما باید **ادمین** کانال باشد با دسترسی *ارسال پیام*. اگر نباشد، tgkit خودش می‌گوید مشکل همین است، نه اینکه بی‌صدا شکست بخورد.

**فایل‌های بالای ۲ گیگابایت** به‌صورت یک پیام تک نمی‌توانند در تلگرام وجود داشته باشند — برای این‌ها vault را استفاده کنید که هر فایلی را به تکه‌های رمزنگاری‌شده‌ی ۱۹ مگابایتی می‌شکند و هیچ سقف حجم کل‌ای ندارد:

```bash
tgkit vault upload huge_dataset.zip --to @mychannel --encrypt
tgkit vault download <لینکی که tgkit چاپ می‌کند>
```

## بخش ۴ — کارهای مفید دیگر

| دستور | چه کاری می‌کند |
|---|---|
| `tgkit doctor` | چک سلامت همه چیز + گفتن راه حل |
| `tgkit status` | نمایش کانفیگ، بات‌ها و توانایی‌ها |
| `tgkit scan run <link>` | خواندن کل تاریخچه‌ی کانال داخل دیتابیس |
| `tgkit copy <link> --to @chan` | کپی پیام‌ها بدون هدر «Forwarded from» |
| `tgkit forward <link> --to @chan` | فوروارد معمولی (با هدر) |
| `tgkit vault upload/download` | ذخیره‌سازی رمزنگاری‌شده و تکه‌تکه برای فایل‌های عظیم |

برای دیدن همه‌چیز `tgkit --help` (یا `tgkit <دستور> --help`) را اجرا کنید.

## رفع اشکال

**`Config not found`** — اول `tgkit init` را اجرا کنید، بعد `tgkit bot add <TOKEN>`.

**خطای `file is too big` / شکستن دانلود روی فایل‌های بزرگ** — این همان دام قدیمی ۲۰ مگابایتی Bot API است. از `tgkit fetch` استفاده کنید (همیشه MTProto). با `tgkit doctor` مطمئن شوید api_id/api_hash ست شده‌اند — این کلیدها هستند که درِ فایل‌های بزرگ را باز می‌کنند.

**خطای «بات ادمین نیست» / شکست آپلود** — بات را ادمین کانال مقصد کنید: تنظیمات کانال → Administrators → Add admin.

**`ApiIdInvalid` / بالا نیامدن MTProto** — api_id/api_hash شما اشتباه است. از https://my.telegram.org نسخه‌ی درست را بگیرید و کانفیگ را به‌روز کنید.

**خطاهای نشست خراب** — پوشه‌ی `~/.tgkit/sessions/*` را پاک کنید و دوباره اجرا کنید؛ بات‌ها با توکن خودشان دوباره لاگین می‌کنند.

**هر چیز دیگری** — اول `tgkit doctor --deep` را اجرا کنید. این دستور ۹۵٪ موارد را تشخیص می‌دهد و راه حل دقیق را چاپ می‌کند.
